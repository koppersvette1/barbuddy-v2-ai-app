# **App Name**: BarBuddy: Your AI Mixology Navigator

## Core Features:

- Inventory Scanning: Use OCR to scan the user's bar inventory from photos or use barcode scanning, categorizing items for intelligent recipe suggestions and substitution logic.
- Intelligent Recipe Generation: Based on the scanned inventory, generate cocktail recipes. Suggest substitutions using 'Flex-Bar' logic and flavor profiles when ingredients are missing, with the ability to create entirely new drinks based on the available ingredients. It will use a tool to decide when substitutions are required
- Pairing Suggestions: Provide food and wood pairings based on the selected cocktail, or suggest cocktails that pair with the user's meal. 
- Settings & Preferences: Allow users to toggle feature sets like 'Show Alcohol', 'Show Mocktails', 'Has Smoker' to customize the app's suggestions.
- Smoke Suggestion: Suggest appropriate wood pairings based on the selected cocktail.
- Step-by-step instructions: Display step by step instructions

## Style Guidelines:

- Primary color: Rich copper (#B87333) to evoke the warmth and elegance of aged spirits.
- Background color: Soft beige (#F5F5DC) providing a neutral backdrop that enhances the vibrancy of the copper and ensures readability.
- Accent color: Deep red-brown (#8B4513) reminiscent of dark wood and spice, adding a touch of sophistication.
- Headline font: 'Playfair' serif font for an elegant, high-end feel, especially suitable for shorter text. Body Font: 'PT Sans' to complement with clear, modern body text.
- Use custom-designed icons featuring classic bar tools and ingredients, with a slightly vintage aesthetic.
- Emphasize visual clarity with well-organized content sections for recipes, inventory, and pairings.
- Subtle transitions for loading new recipes and displaying ingredient substitutions, offering a smooth user experience.
